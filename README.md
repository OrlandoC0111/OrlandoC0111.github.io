# OrlandoC0111.github.io

Personal academic website of Orlando Chen (Virginia Tech, School of Plant and Environmental Sciences), served at https://orlandoc0111.github.io.

Built from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (MIT License). The GitHub Actions workflow in `.github/workflows/jekyll.yml` rebuilds and deploys the site on every push to `master`.

Where to edit:

| What | File |
|---|---|
| Name, sidebar bio, links (ORCID, Scholar, LinkedIn) | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Home page | `_pages/about.md` |
| Research page | `_pages/research.md` |
| CV | `_pages/cv.md` (PDF goes in `files/`) |
| Presentations | one file per talk/poster in `_talks/` |
| Publications | one file per paper in `_publications/` |
| Profile photo | replace `images/profile.png` (square, ~400 × 400 px) |

Search for `TODO` to find the placeholders still to fill in.
